    ```markdown
    # readk.it

    Convert any EPUB into a clean, self-contained reading experience that works in any modern browser — desktop, mobile, or tablet — with zero runtime dependencies on a third-party EPUB library, on a build any contributor can reproduce on a current developer machine.

    readk.it has two faces of one engine: a **Node TypeScript build script** that consumes `.epub` files and emits one self-contained HTML per book, and a **browser drag-drop reader** that runs the **same** isomorphic TypeScript EPUB-processing engine in the browser, rendering into the **same** Lit reader chrome. A static **library index page** is an optional secondary output. There is no backend.

    > Status: under active rewrite (Phase 1 of 13 complete: TypeScript + Vite + Lit toolchain + repo hygiene gates). The build script (Phase 10), drag-drop entry (Phase 9), library index (Phase 11), and GitHub Pages deploy (Phase 13) are not yet shipped — see `.planning/ROADMAP.md`.

    ## Supported browsers

    Last 2 versions of Chrome, Edge, Firefox, Safari (desktop + iOS Safari), Chrome Android, and Firefox Android. **No IE, no pre-Chromium Edge** — that was the 2013 floor and is no longer relevant.

    ## Prerequisites

    - **Node 22 LTS** (`.nvmrc` says `22`; use `nvm use`, `fnm use`, or `mise use`).
    - **npm 10** (ships with Node 22).
    - **Do not use pnpm or yarn.** `engine-strict=true` in `.npmrc` rejects them, and the committed lockfile is `package-lock.json` only.

    ## Install

    ```bash
    git clone git@github.com:jcdarwin/readk.it.git
    cd readk.it
    nvm use # or fnm use / mise use — picks up .nvmrc
    npm install
    ```

    `npm install` runs the Husky 9 `prepare` step which sets `core.hooksPath=.husky/`. **Do not pass `--ignore-scripts`** — it disables the pre-commit hook that defends repo hygiene.

    ## Dev loop

    | Command | What it does |
    |---------|--------------|
    | `npm run dev` | Vite dev server at `http://localhost:5173/`, HMR. Phase 1 serves a placeholder `<readkit-app>` shell; Phase 6 replaces its body with the real chrome. |
    | `npm run typecheck` | Strict TypeScript (`tsc --noEmit`) against `tsconfig.json` (browser tree) AND `tsconfig.node.json` (`vite.config.ts`, `eslint.config.js`, `tools/`). |
    | `npm run lint` | ESLint 10 flat config: `tseslint.configs.strictTypeChecked` + `eslint-plugin-lit` + `eslint-config-prettier`. |
    | `npm run format` | Prettier 3 on the whole tree (config at `.prettierrc.json`; ignore set at `.prettierignore`). |
    | `npm run build` | Vite production build (Rolldown internals; `rolldownOptions` not `rollupOptions`). Phase 1 builds the dev shell only; Phase 10 adds the per-book HTML pipeline; Phase 11 adds the library index; Phase 13 adds the gh-pages publishing flow. |
    | `npm test` | Phase 1 placeholder (`echo 'tests land in Phase 2' && exit 0`). Vitest + Playwright land in Phase 2. |

    Pre-commit hook (`.husky/pre-commit`) blocks any staged file > 1 MB and runs `lint-staged` (ESLint + Prettier on changed files only).

    ## Repo layout

    ```
    .
    ├── src/
    │   ├── engine/      # fflate + fast-xml-parser + DOMPurify quarantined here. No other module imports them.
