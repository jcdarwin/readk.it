The new tree (TypeScript 6 + Vite 8 + Lit 3 on Node 22 + npm 10) has zero overlap with the legacy 2013-era stack (Grunt 0.4 + RequireJS + jQuery + Compass + Node 0.11). Where the legacy tree provides a **negative analog** (i.e., a "do NOT copy this; the new file must explicitly contradict it" reference), it is cited below.

### `.husky/pre-commit` (hook script, event-driven)

**Analog:** none.

**Pattern to apply:** Two-step setup per **RESEARCH.md "Pattern 2: Husky 9 setup (modern flow)" lines 365-410**.

Step 1 — Initialise (one-time, run by the planner-executor):
```bash
npm install --save-dev husky
npx husky init
```
This writes `.husky/pre-commit` placeholder, adds `"prepare": "husky"` to `package.json` (already in the skeleton above), and sets `core.hooksPath=.husky`.

Step 2 — Replace the placeholder with the production hook (RESEARCH.md lines 384-406):
```bash
#!/usr/bin/env sh
# Block files larger than 1 MB
LIMIT=$((1024*1024))
files=$(git diff --cached --name-only --diff-filter=ACMR -z | tr '\0' '\n')
if [ -n "$files" ]; then
  while IFS= read -r f; do
    [ -z "$f" ] && continue
    if [ -f "$f" ]; then
      size=$(wc -c <"$f" | tr -d ' ')
      if [ "$size" -gt "$LIMIT" ]; then
        echo "ERROR: $f is ${size} bytes (>1 MB). Reject." >&2
        exit 1
      fi
    fi
  done <<EOF
$files
EOF
fi

# Run lint-staged
npx lint-staged
```

**Anti-patterns to avoid (RESEARCH.md lines 519-528):**
- Do NOT use the v8-era shebang shim (`. "$(dirname -- "$0")/_/husky.sh"`). v9 doesn't need it.
- Do NOT use `husky add .husky/pre-commit "..."` — removed in v9. Edit the file directly.
- Do NOT use `husky install` in `prepare` — v9 uses bare `husky`.

**Pitfall 6 (RESEARCH.md lines 614-619):** The `tr` normalisation is adequate but not bulletproof against filenames with embedded newlines/spaces. Planner may opt to harden with a strict NUL-delimited `while IFS= read -r -d '' f` loop. Acceptable as-is for v1.
